# FinGuard V0.9 Release Gate

当前 V0.8 仅作为本地内测基线，不进行公网发布。

## 必须通过

- [ ] `python scripts/release_check.py` 无阻断项
- [ ] 强制登录开启
- [ ] 邮箱验证码使用真实 SMTP
- [ ] 开发验证码模式关闭
- [ ] DeepSeek、SMTP、数据库凭证不在源码和 Git 历史中
- [ ] SQLite 完整性检查为 `ok`
- [ ] 至少完成一次备份下载和恢复演练
- [ ] 管理员、审计员、会计、只读角色分别完成 E2E
- [ ] 浏览器端完成注册、登录、项目、上传、审计、复核、导出和退出
- [ ] PostgreSQL 迁移、备份和恢复通过
- [ ] 发布包具有明确版本号和回滚包
- [ ] 错误监控、健康检查、日志和告警可用
- [ ] 真实用户仅使用脱敏或虚构数据进行首轮试用

## 发布阻断条件

- 数据库损坏或恢复失败
- 企业之间发生数据串读
- 借贷不配平仍可生成报表
- AI 失败导致页面崩溃
- 明文密钥进入源码或仓库
- 忘记密码流程无法恢复账号
- 部署后无法回滚

## 发布命令

```powershell
python scripts/release_check.py
python scripts/browser_e2e.py
python -m pytest -q
ruff check --no-cache .
ruff format --check .
```
