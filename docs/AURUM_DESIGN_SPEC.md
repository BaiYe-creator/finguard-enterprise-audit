# AURUM 极简高级感视觉规范

本规范从用户提供的《极简高级感_提案文档.docx》《极简高级感_模版使用说明.docx》
和《极简高级感_演示模版.pptx》中提取，仅用于 FinGuard 高管简报的视觉实现。

## 色彩

| Token | Value | Usage |
| --- | --- | --- |
| Deep Ink | `#12161B` | 深色封面、主文与饼图交替色 |
| Warm White | `#F7F5F0` | 内容页背景 |
| One Gold | `#B08C5A` | 强调线、数字和图表 |
| Fine Line | `#DCD6CA` | 极细分隔线 |
| Body Gray | `#5E656E` | 正文说明 |

## 字体

- 标题：Noto Serif SC Light
- 正文：Noto Sans SC Light
- 顶部英文标签：8–9 pt
- 页面标题：25 pt
- 数据主值：28–42 pt
- 表格及注释：8–12 pt

## 网格与页面

- 16:9，13.333 × 7.5 英寸
- 左右页边距：0.92 英寸
- 12 栏内容网格
- 栏间距：0.18 英寸
- 页脚基线：6.92 英寸
- 极细线仅使用 `#DCD6CA`，不使用阴影和夸张形状

## FinGuard 页面映射

| 页面 | 版式 |
| --- | --- |
| 封面 | 保留原模板深墨背景图，替换为 FinGuard 标题 |
| 数据支撑 | 暖白背景，四组大数字，12 栏分栏 |
| 风险趋势 | 原生簇状柱图，一金色 |
| 重点凭证 | 仅水平细线的 Top 5 表格，AI 意见置于表格下方 |
| 饼图 | 深墨与一金严格交替 |

实际生成器位于 `finguard/ppt_generator.py`，母版位于 `assets/template.pptx`。
